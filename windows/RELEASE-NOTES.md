Windows 10 / 11 64 位（Intel / AMD）首版。

下载 **BlackboardDesktop-Windows-x64-Setup-v1.0.0.exe** 按向导安装。也可下载 ZIP，完整解压后运行 BlackboardDesktop.exe。

包含桌面作业卡片、逾期与待交分组、详情页截止时刻、15 分钟自动同步、手动刷新、原作业入口和本机已处理标记。关闭卡片保留任务栏右下角托盘图标，可随时恢复。

启动时使用学校官方登录页，每位使用者自行登录。发布包不包含真实账号、密码、个人作业或登录缓存。程序独立运行，不依赖 Codex，已经包含 .NET 运行时；若本机缺少 Microsoft Edge WebView2，应用会提示前往微软安装。

验证：GitHub Windows 环境编译、原生程序启动、WebView2 模拟页面读取、上午/下午/午夜截止时刻、缓存保护、关闭隐藏与托盘恢复、安装程序安装后再启动检查。没有使用真实学校账号进行 Windows 在线登录测试。

本程序尚未进行 Windows 代码签名，系统可能显示未知发布者。SHA256SUMS.txt 可用于核对下载文件。

macOS 用户继续使用原有 v1.0.0 macOS 发布包。
